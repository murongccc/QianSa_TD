# 图片播放模式音柱加宽25%

图片播放模式沿用已经缩小的80–100像素呼吸半径，将音柱横向宽度阈值由384/416/480提高至480/520/600，恰好增加25%。圆帽中央宽度仍为柱身阈值的一半，同步增加25%。实际可见宽度受像素取整影响。

游戏模式仍使用384/416/480，保留原半径、柱长、位置和颜色。阈值信号扩展为10位，确保520与600不会被截断；横向误差比较显式补零至16位。没有修改顶层、时钟或管脚。

回归以5717585版本为基线：图片模式逐像素验证加宽边界、原有像素保留、确实新增可见像素，以及半径和柱长不变；游戏模式逐像素验证输出和颜色与原版一致，并覆盖21个半径、256档幅度和两种音柱数据读取方式。另运行兼容模式、参考模式和视频合成测试。

本次只运行局部仿真，不运行综合、布局布线或生成bitstream；板上视觉效果及实现时序待后续确认。

验证结果：ModelSim编译0错误、0告警；上述五组局部仿真全部通过。缓存读取与宽总线读取各完成979,200次检查，游戏模式可见像素均为10,620；视频合成验证921,600像素，帧边界切换和两拍对齐正常。`git diff --check`通过。
