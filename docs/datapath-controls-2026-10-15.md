## 最终保留的结构

### 缩放器：区分控制复位与工作数据初始化

保留状态机以及 `busy/done/src_ready/dst_valid/dst_pixel/dst_x/dst_y/dst_last/dst_frame_last` 的原有外部行为，含无效周期的输出值。状态转换和每像素计算拍数不变，分离工作寄存器和控制寄存器的时序块，保证每个寄存器只有一个驱动。

| 内部工作数据 | 初始化或覆盖点 | 消费点/保持要求 |
|---|---|---|
| 尺寸 sw/sh | IDLE 接受 start 时完整锁存 | 后一拍 VALIDATE 后才参与帧处理 |
| 坐标、步进、相位、填充位置 | VALIDATE 完整初始化 | 检查/填充/计算状态才消费 |
| 除法整数、商、余数、除数、计数 | DIV_X_INIT / DIV_Y_INIT | 对应 RUN 状态；单行/列跳过的步进已初始化为零 |
| 权重 | 每拍采样当前坐标 | READ0 后坐标稳定，在 READ2 及后续计算状态消费 |
| p00/p01 | 每拍采样同一 RAM 读口 | 相邻拍分别消费 x0/x1，允许综合共享存储 |
| p10/p11 与 h0 | 保留原采样/保持使能，去掉数据复位 | 完整采样后跨多拍保持到实际消费点 |
| acc | 每拍保存乘积 | BASE 后下一拍 ACC 消费；水平乘积小于 2^16，原高八位补零等价 |
| h1、v | 每拍保存相应 sum | 分别在 H1_ACC 后的 V_BASE、V_ACC 后的 PACK 消费 |
| DSP 操作数 | 原调度拍注册采样，非计算状态写零 | 下一拍消费；保留三 DSP 和既有精度 |
| 行末/帧末内部标签 | READ0 完整写入 | PACK/EMIT 消费前已经有效 |

reset/abort 仍将控制状态回到 IDLE、关闭对外有效信号；重启会重新走锁存、初始化、填充和完整计算序列。工作寄存器不要求在无效周期有确定值，但输出寄存器的复位值保持不变。没有删除缩放器或改成最近邻，没有改变 16 位相位、8 位权重或最终舍入。

### 目录器：简化描述符写入数据的控制

64 位 `cache_write_shift` 与槽号属于写数据暂存，改为无复位。完整目录项的最后一个字节到达时装载 64 位描述符；其他拍固定右移 16 位，去掉空闲保持使能。槽号仍在原目录项装载拍捕获，写入期间保持。

RAM 写使能 `cache_write_busy && !rst`、四字写入的 `cache_write_word`、候选计数和发布控制保留原复位。第一次 RAM 写入前，数据和槽号已完整装载；复位中断写入时禁止 RAM 写入，候选计数隔离旧内容。描述符缓存容量、候选顺序、完整 32 位簇号和文件长度均不变。

## 等价与功能验证

这里的等价验证是固定基线的逐拍 RTL 仿真对照及独立像素模型，未声称完成任意输入空间的形式等价证明。

- **保留缩放器完整回归**：六种输出尺寸和全状态取消重启，共七组通过；640×480 配置完成十个完整帧、3072000 个完整帧像素对照，仿真时间 390077820 ns。覆盖最大源 1920×1080、1919×1079、1×1、2×2、单行/列、黑白/高对比/彩色、输入空拍和输出反压。全部外部数据及握手逐拍比较，正常尺寸另用独立 64 位坐标和双线性公式逐像素核对。
- **20个活动状态取消重启**：每个状态分别 reset、abort 后不再复位重启，共40个中断位置；消费拍另比较累加器、垂直结果与基线，确认旧数据不外泄。
- **厂商模型复核**：最终保留 RTL 另用安路官方乘法器模型通过边界尺寸、退化配置、全状态 reset/abort 六组回归。完整十帧回归使用的无符号组合乘法模型对应保留 RTL 中 INPUTREG/OUTPUTREG 均禁用的原语配置；官方模型复核避免把简化模型用于不支持的寄存器配置。
- **目录逐拍对照**：直接 FAT32 / MBR 两组，各1792个字段穷举，共3584组，分别比较1701969和2683089拍；所有对外信号与内部解析判定一致。
- **目录协议回归11组**：0～5项候选、四字缓存写入、写入中复位、FAT末项及同拍done等均通过，使用真实 BRAM 模型。
- **最终真实FIFO集成3组**：普通图片帧提交、音游图片帧提交、预装后延迟音频启动通过。前两项各14条可选端口既有告警，音频项零告警；均无仿真错误。
- HUD 两个未保留候选另各通过八种配置、400万拍显示输出/字符写入对照；不将这些候选的通过结果混作最终 RTL 的新增功能。

基线与保留候选综合报出的告警均73条，类别和数量一致，无综合错误。综合估计 setup WNS/TNS 均为 −0.213/−3.408 ns、hold +0.471/0 ns；这不是最终路由时序。由于仍有容量错误，**不能宣称时序闭合、布线完成或可生成可用位流**。

工作数据自由更新可能增加部分计算阶段的内部切换，未实测功耗；对外周期和数据保持行为已对照。没有修改工作频率、复位同步器或约束以换取面积数字。
