# 游戏与频谱共显布局（2026-10-13）

## 显示行为

640×480 游戏画面采用左侧四轨、右侧环形频谱。退出游戏后恢复原来的居中频谱。

| 元素 | 坐标或尺寸 |
|---|---|
| 四轨 | x=16..335，每轨80像素；边界16/96/176/256/336 |
| Tap/Hold头部 | 宽56、高32像素，沿用原有圆角和箭头/短横标记 |
| 判定线 | y=384..385，纵向音符几何及240采样帧/像素滚动速度不变 |
| 游戏频谱 | 中心(488,240)，最大外半径120像素 |
| 非游戏频谱 | 原中心(320,240)，原半径、音柱幅度、颜色和频段选择 |
| 游戏进度条 | 从x=16起，满长度320像素 |

分数、连击、状态、曲名与难度HUD沿用原显示位置。图片背景在游戏中仍压暗，HUD、音符、判定线覆盖频谱，触摸光晕使用位或提亮合成。

## 实现与时序考虑

- `rhythm_game_renderer`默认`COMPACT_LAYOUT=1`，所有横向音符和光晕坐标同步收窄；设为0可使用旧几何，历史回归显式选择旧布局。
- 进度条将原来的448=7×64改为320=5×64，继续复用同一DSP和现有串行除法，不增加乘法器或快照周期。
- `touch_lane_input`默认选择新轨道原始阈值：486/2494/4503/6512/8521。使用既有标定反算`96+ceil((pixel_x×65536−32768)/2610)`，纵向阈值6962（像素y≥352）不变。
- 一个`ring_spectrum_renderer`复用既有FFT和频谱缓存。游戏内半径为`floor(radius×2/3)`，半径和平方同级查表；音柱长度为`floor(full_length×3/4)`，只增加小位宽加减，最大73+47=120像素，有声最低长度6像素。
- 普通中心320和游戏中心488分别使用常量比较/减法并行计算横向绝对距离，再按帧模式选择结果。模式信号不进入动态中心的比较/减法进位链。
- `video_presentation`的游戏状态在帧边界锁存，同时选择频谱中心和大小。游戏频谱复用准确的行末计数`touch_y`，与轨道扫描对齐；非游戏沿用原扫描坐标，保留原像素效果。
- 频谱幅度、几何和布局标志保持同像素第一级锁存，合成继续使用原有第二级；顶层DE/VS两拍延迟不变。未修改顶层、时钟、管脚或厂商IP。
- 游戏频谱不依赖BMP有效标志，底图无效时仍显示频谱和游戏图层。

## 验证

局部回归脚本：`src/test/run_game_spectrum_regression.py`和`src/test/run_touch_lane_regression.py`。日志分别位于`prj/log/game_spectrum_20261013/`和`prj/log/touch_lane_20261011/`。

- 普通频谱整帧307,200像素与固定修改前版本`017df025`比较；游戏频谱遍历21种呼吸半径、256种幅度，并检查整帧边界。
- 真实同步幅度缓存与宽总线两种配置分别验证，共979,200次精确比较/配置；最大幅度小频谱绘制10,620个像素，全部位于120像素半径内。
- 游戏合成检查三帧921,600像素，包括不透明音符、光晕提亮、帧中请求切换、退出恢复和无BMP背景。
- 窄轨音符采用独立逐像素参考，覆盖圆角、Hold尾帽、重叠、裁剪、判定时刻和按住锚点；同步与分布式几何均验证。
- 触摸原始X/Y各65,536值全域验证；绑定逻辑131,072坐标报告及10,000状态报告对照，并覆盖解析器、双指、Tap/Hold和CDC事件。
- 另覆盖窄轨光晕、Hold与底图合成、240采样边界、会话清理、普通视频和320像素进度条的高字、负时间、零时长与限幅。

本次运行两次综合和一次布局布线，使用`--hfn-off`，没有生成bitstream。第二次综合用于一次布线发现关键路径后的结构修正，没有重复布局布线。
