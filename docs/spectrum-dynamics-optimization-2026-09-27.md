# 环形频谱频段与动态映射优化

## 实现与边界

当前顶层仍为 48 kHz 左声道、256 点 FFT、32 个分析频段和 64 根插值音柱。
顶层接口、管脚、PLL、音频播放链和厂商 IP 未修改。保留工作区原有工程/PLL 文件改动。
未生成 bitstream。512 点参数模式保留，并通过局部回归。

- 最高显示频点由 24 kHz 改为 15.9375 kHz，避免最后两柱长期只对应 20.8–24 kHz。
- 在线性幅度域按约 75% 峰值、25% 均值汇总，再恢复 Hann 的约两倍相干增益。
- 高频补偿采用 Q1.8 的 `256+8*band_index`，由 1.0 倍平滑增加至 1.96875 倍。
- 对数等级近似 `24*log2(M/32)`，门限为 32，饱和至 255。19 位最高有效位定位、16 项小数表的全输入域单调性已验证；未饱和区与解析值误差不超过 3 级。
- 上升步长为差值的二分之一向上取整，回落为八分之一向上取整，取消 2 级死区。
- 整组频段非零时所有柱至少有 2 像素径向厚度；整组归零后全隐藏。短柱在最终距离判断中合并，避免在半径平方前增加选择链。柱间间隙和彩虹配色保留。
- 均值、混合、补偿、对数和发布分拍计算；仍在视频帧边界一次发布全部频段。
- 四个计算中间寄存器不增加异步复位负载；状态机和可见输出照常复位，每个中间值都在发布前覆盖。新增五个计算阶段中途复位的恢复检查。

峰值保留 17 位，累加保留 22 位，均值乘积保留 30 位，补偿乘积保留 27 位。
均值倒数为 Q0.7 近似；它的误差仅通过四分之一均值权重影响混合幅度。
采样分辨率仍为 187.5 Hz，64 柱不是 64 个独立分析频段，也不能区分更低的相邻低音。
有声判断沿用整组平滑频段非零，因此停止输入有效 PCM 不等于静音；正常播放器需继续提供零 PCM 才能让频谱衰减。

## 仿真与真实 WAV 对照

ModelSim 编译及以下测试均为 0 错误、0 告警：

- 256/512 点 FFT：单/双频、弱音、非整数频点 Hann 扫频、32 段遍历、最高频扫描结束、缓冲切换、视频帧边界发布、衰减归零和复位。
- 19 位幅度输入全域 524288 个值的单调性；未饱和区对数误差检查。
- 低/中/高频的 −24、−18、−12、−6 dBFS 幅度递增及两帧可见上升。
- 渲染：64 个中心、逐频段激活、2 像素短柱全画面扫描、间隙、末柱无环绕、静音全隐藏、圆形边界及配色。
- 视频呈现：OSD、超时、图像调整、锐化、叠加优先级、启动和运行中显示切换。

256 点模式稳定等级：

完整逐柱范围、5%–95% 分位范围和平均变化保存在 `docs/spectrum-wav-comparison-2026-09-27.json`。
中高频的频段范围已经改变，柱号相同不代表两个版本在这些柱上分析完全相同的频率。

**不能把本次对照解释为所有音柱都更活跃。** 该 WAV 的蓝色区分位波动范围由平均 34.525 px 缩至 19.150 px，逐帧变化也减小。
对数曲线提高弱音等级并压缩强弱差距，能避免强音过早封顶，却不能保证特定歌曲的低频柱有更大的视觉摆幅。
这段 WAV 的原版封顶本来就很少，不能用它证明照片中常高的蓝柱主要由饱和引起。
本轮完整实现批准的固定对数映射；照片对应歌曲的蓝柱效果仍需上板比较，未擅自混入节拍或独立 AGC。

人工 500000/8388608 满幅直流偏置能使第一频段亮起，因为 Hann 窗会将直流泄漏到 bin1。
真实 WAV 左声道均值为满幅的约 0.003792%，RMS 约 22.3343%；目前不支持将其蓝柱常高主要归因于直流。
未增加去直流滤波器，保留正常低音响应。

## 上板比较与 GitHub 参考

用户在 TD GUI 从综合开始重新运行，确认资源、setup/hold，并自行生成 bitstream。
用照片对应歌曲、相同音量，记录普通段与高潮段：检查左上角短柱是否完整、蓝色起始柱是否仍常高、中高频是否跟随变化，随后静音观察是否全部消失。
同时回归播放、切图、图像参数和字幕。不能将仿真通过视为板级视觉验收或整机稳定性通过。
