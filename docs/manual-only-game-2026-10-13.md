# 游戏固定为四轨手动输入

板级游戏引擎固定 `input_mode=2`，会话控制器的 `auto_mode` 固定为零。进入游戏、重开和暂停恢复均使用触摸手动输入；触摸桥原有的清队列和松开后重新武装规则继续生效。

KEY4 从游戏模式选择中断开，按下不会切换输入模式、取消会话或重载歌曲，也不会阻止 KEY2/KEY3 重新武装。KEY2 重开、KEY3 暂停/恢复、SW1 运行控制及进入游戏的开关条件保持原值。图片模式中的按键参数调整和 SW2 自动轮播保持原值。

HUD 固定显示 `MANUAL`，删除 AUTO/TEST 文字分支和模式文字寄存器。文字 ROM 生成脚本同步更新。会话保留原端口以兼容测试，旧模式键输入被忽略。通用引擎的自动输入代码仍可用于独立历史算法测试，但板级固定手动配置已将该逻辑综合裁剪，最终板级网表不含 `auto_input` 实例。

手动模式的视图地址直接来自渲染器，不再选择自动扫轨地址。1.25 倍滚动速度、Hold 长条和无黑框光晕保持原值。

## 验证与资源

会话回归验证默认手动、KEY4 在运行/暂停/结果页均无效、KEY2 重开、KEY3 暂停恢复和取消退场。实际 HUD 字节检查为 `MANUAL`。四轨触摸到真实判定核心回归覆盖 Tap、双押、Hold 成功和提前松开、背压、释放顺序、重新武装及身份替换。
