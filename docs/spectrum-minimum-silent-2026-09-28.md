# 弱柱最低高度与 SD 加载静音

## 修改

- 板级使用的参考频谱模式：有声时每根柱的最低径向长度由 2 px 提高到 4 px，更接近参考图右上方的短柱。采用最低高度限制，超过 4 px 的柱长计算不变，内圆半径仍为 90 px。保留细线、圆帽、80 柱与静音全隐藏。旧兼容模式仍为 2 px。
- `pcm_audio_player.v` 原来在播放状态且 FIFO 没有可用采样时输出 ±1000000 的 24 位方波，每 24 个采样翻转一次，48 kHz 下为 1 kHz。这就是 SD 初次加载期间软件逻辑产生的“滴”声来源。改为左右声道补零，删除方波计数器；48 kHz audio_valid、FIFO 预取、音量、暂停、停止以及 underrun 标志保持。
- 缺数据补零同时适用于播放途中的 FIFO 欠载；数据回来后继续播放。不修改顶层端口、管脚、PLL、厂商 IP 或 FFT。

## 验证

- ModelSim 编译 0 错误、0 告警。
- `tb_reference_ring`：80 柱直接选择、所有弱柱 4 px 最低高度、最低高度外像素不显示、静音隐藏通过。
- `tb_ring_spectrum_renderer`：旧模式 80 扇区、插值、圆帽、2 px 最低高度与静音通过。
- `tb_pcm_audio_player`：启动 FIFO 空状态跨过 96 个以上采样（覆盖原方波多个周期），所有有效采样均为零；播放中欠载静音、欠载标志、恢复播放、左右声道与音量缩放、暂停与停止通过。该测试已加入常规频谱回归入口。
- `tb_video_presentation -gREFERENCE_SPECTRUM=1`：视频叠加与同步通过。局部日志位于 `prj/log/spectrum_minimum_silent/`。
- 一次综合完成、退出码 0、无错误，资源为 LUT 15314/19600（78.13%）、REG 10270/19600（52.40%）、BRAM9K 含 FIFO 53/64、BRAM32K 6/16、DSP 20/29、PLL 2/4。实际资源以 `prj/log/spectrum_minimum_silent_syn/SD_to_Video_gate.area` 为准。综合日志 WARNING 匹配 60 行，与上一候选相同（含工具汇总行），保留厂商 FIFO 未驱动端口与 RAM 初值等既有告警。
- 本轮只做综合检查，未重新布局布线。综合阶段时序估计 setup WNS −0.471 ns、TNS −3.879 ns，不代表布线后的时序；上一候选已有 hold/removal −0.075 ns 违例，不能据本轮局部测试宣称工程时序通过。

## 上板检查

由用户生成 bitstream 后冷启动，检查 SD 卡加载期间没有原 1 kHz 提示音，音乐开始后正常播放；选择普通段与弱音段确认短柱更明显，完全静音后整圈消失。当前验证为数字逻辑仿真，未实际听音或检查电视自身切换 HDMI 时的声音。

本轮不生成 bitstream。既有工程/PLL 改动保留。
