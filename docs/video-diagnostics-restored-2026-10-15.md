- 数码管恢复完整的六页轮换，每页 2 秒：刷新间隔 → B → D → F → C → A。

## 板上读取

四位数值均为十六进制，事件计数达到 `FFFF` 后饱和，复位后清零。

| 页面 | 含义 |
| --- | --- |
| 刷新间隔（正常无字母，故障显示 E） | SDRAM 刷新确认最大间隔，单位为 100 MHz 内存时钟周期；沿用现有策略，范围不超过 `09C4`，历史实板正常值为 `08D3` |
| B | 视频读 FIFO 空读次数 |
| D | `video_delay` 输出、图像处理前原始 RGB 的同槽帧签名或像素数异常次数 |
| F | 视频域读 FIFO 输出的同槽帧签名或像素数异常次数 |
| C | SDRAM 返回事务的签名或返回字数异常次数 |
| A | HDMI AXIS 有效期间 `ready` 为低的周期数 |

发生彩线后先不要复位，关闭自动轮播，停在同一张图片上，记录完整一轮页面数值，
再观察一轮哪些计数仍在增加；最后与复位后恢复正常时的结果比较。
同样记录刚显示图片后闪烁 1～2 秒时和闪烁停止后的读数。

## 解释边界

- B、D、F 在显示启动保护放行后才开始监视，不覆盖此前的全部预热过程。
- D、F 为每个图片槽分别建立基线，不能证明第一份基线与原 BMP 完全一致。
  初次写入即已损坏且随后保持稳定的图片可能不会使计数持续增长。
- C 沿用原模块的单一事务基线，没有按图片槽分别保存基线；加载过程、切换不同图片、
  不完整的预取事务都可能使它增长。应在加载完毕且同槽静止时观察趋势，
  不能仅凭 C 非零判定 SDRAM 损坏，也不能把 C/F/D 的绝对计数逐项比较。
- A 非零表示曾发生反压，需结合发生阶段和计数是否持续增长判断。
- 参数置 `0` 仍可裁剪签名逻辑，同时保留刷新、B、A 三页。
