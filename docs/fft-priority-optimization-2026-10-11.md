# FFT 与环形频谱资源优化实施记录

2026-10-11。保持 Hann、keep、2048点/48kHz、80柱、数值取整、重力回落、呼吸、颜色及原帧发布时间。资源优化完成；整体时序尚未闭合，物理setup较基线恶化，不能作为已验证稳定的上板版本。

## 最终改动

| 方法 | 保留的实现 |
|---|---|
| 1：位宽收缩 | 插值结果28→27位、对数输入24→16位、对数规格化/扫描随之收缩、平方根计数5→4位；环形绝对差11→10位、平方表17→14位、阈值/轴线/横向误差18→16位 |
| 2：公共表达式 | 用A×256+(B−A)×f替代两项插值；b_addr由a_addr+step得到；major/minor共用比较 |
| 3：常数运算 | 对数整数项使用八项精确表，保留加8后的原舍入，小数表和240饱和不变 |
| 4：互斥复用 | 将有符号差值拆成高5位和非负低15位，在既有ST_BAR_B/ST_BLEND两拍复用16×16蝶形乘法器；回落两个分支共用高11位减法 |
| 5：用户覆盖要求 | display_index上的keep完整保留；ram_style/rom_style也保留 |

ST_BAR_B直接消费本拍同步读出的history_q，避免读到尚未锁存的旧magnitude_b。低部分积按23位非负保存，高部分有符号扩展；29位重建中间量保留符号与保护位，之后取原[26:8]。Hann采样可能与计算并发，继续使用独立乘法器。

最终映射网表核对FFT仅剩两个物理DSP，分别对应Hann与共享乘法器，三片独立插值DSP已消失。所有外部接口、顶层、PLL、管脚、约束、厂商IP、图片双线性缩放及其他功能链的源码均未修改。
